# Aura (test version)

A private journaling and support app for depression, loneliness and difficult relationships, in English and Hindi. This is an early prototype for testers. It isn't a replacement for therapy or emergency help.

- `index.html` is the whole app (served by GitHub Pages).
- `worker.js` is the Cloudflare Worker that holds the API key and writes AI reflections.
- `SETUP.md` has step-by-step deployment instructions.

Journals stay on each tester's device. Only entries a tester chooses to "Reflect" on are sent to the AI.

If you're in danger in India, call 112. To talk to a trained counsellor (free, 24×7): Tele-MANAS, 14416.
